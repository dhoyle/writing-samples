# Why should you choose Zilliz Cloud?

Today’s databases are not designed to work effectively with vector embeddings. Milvus was
specifically designed for vector embeddings, and it can scale up to billions of vector
embeddings.

Zilliz Cloud provides an out-of-the-box Milvus vector database on a fully managed cloud
infrastructure, freeing you from the time, effort, and costs associated with database
management.

Zilliz Cloud can deliver vector search with high performance and very low latency – over 1000
queries per second (QPS).

With Zillliz you can choose the database size and type, and only pay for what you actually
use.

To ensure data security, Zilliz Cloud complies with the SOC 2 standard, and will soon provide
role-based access control (RBAC).
